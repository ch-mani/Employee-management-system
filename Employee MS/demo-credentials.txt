=====================================================
  Quick Start
=====================================================

Prerequisites:
  - Java 17+
  - Maven
  - MySQL 8.0 (running on port 3306)
  - Node.js 18+

1. Create a MySQL database (or it auto-creates):
   CREATE DATABASE IF NOT EXISTS ems_db;

2. Update DB credentials if needed:
   backend/src/main/resources/application.properties
   (default: root / admin)

3. Start backend:
   cd backend
   mvn spring-boot:run

4. Start frontend:
   cd frontend
   npm install
   npm run dev

5. Open http://localhost:3000 and login with
   the credentials above.

Note: When an Admin/HR creates a new employee,
a login account is automatically created with:
  - Email: (the employee's email)
  - Password: password123
